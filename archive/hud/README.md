# HELM 1 HUD (archived)

The Next.js heads-up display that HELM 1 ran on port 3107: the orb, the tabs and the
layout around them. It is kept here as a quarry for the desktop UI that will merge it
with the dashboard. See `docs/adr` for the record that retired it.

Nothing here is built, tested or linted, and its runner, voice server and feeds are
gone. To run it as it last worked, check out the `helm1-final` tag.
